# App Finanzas

Aplicación web de gestión financiera personal desarrollada con React y FastAPI, con persistencia de datos y una interfaz orientada al seguimiento de las finanzas personales.

### Funcionalidades
- Registro, edición y eliminación de ingresos y gastos.
- Clasificación de movimientos por categorías.
- Filtrado de históricos por mes, año y categoría.
- Resumen financiero mensual con ingresos, gastos y dinero disponible.
- Análisis de gastos por categoría y cálculo del gasto medio.
- Gráficos comparativos de ingresos y gastos mensuales.

### Tecnologías
- **Frontend:** React, JavaScript y CSS.
- **Backend:** Python y FastAPI.
- **Base de datos:** según la configuración actual del proyecto.

Proyecto personal desarrollado con fines de aprendizaje y práctica de desarrollo web full-stack.
